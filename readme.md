# This is a Home Budget App

Simple web application for managing your personal budget.  

# Features

- Add income/s and expense/s
- Edit and delete entries
- Summary of total incomes, expenses, and remaining budget

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 4 (for modal functionality)

# How to Run

1. Clone or download the repository.
2. Go live `index.html` in your web browser.
3. Use the app to manage your budget.
